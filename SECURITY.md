# Security Policy

## Project status

This repository is pre-alpha documentation and does not currently ship a public analysis engine. Do not rely on it as a security boundary, forensic system, or sandbox.

## Reporting a vulnerability

Do not publish credentials, personal data, private samples, or exploitable details in a public issue. Use GitHub private vulnerability reporting if enabled. Otherwise contact the maintainers through a verified private channel with the affected commit, impact, minimal reproduction, and suggested mitigation.

## Security expectations

- Treat all artifacts and parser outputs as untrusted.
- No automatic execution of analyzed artifacts.
- No implicit upload of artifact contents.
- Network behavior must be explicit and documented.
- Third-party engine versions, licenses, and vulnerabilities must be tracked.
- Security fixes and release notes must describe affected versions and limitations.
